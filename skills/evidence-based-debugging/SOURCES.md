# Source and adaptation

The reproduction-loop techniques draw on Matt Pocock's [diagnosing-bugs](https://github.com/mattpocock/skills/blob/bbadaa631c37af594e5a05c9cefacd9956136b18/skills/engineering/diagnosing-bugs/SKILL.md) at reviewed revision `bbadaa631c37af594e5a05c9cefacd9956136b18`. Retained [MIT notice](LICENSE).

Adds minimized symptom-specific feedback, trace replay, differential checks, and safe bisection to the existing evidence-based method. It omits universal mandatory phases, guarantees about bug resolution, automated production changes, and unbounded persistence. Existing assignment, failure classification, and stopping rules remain authoritative.
